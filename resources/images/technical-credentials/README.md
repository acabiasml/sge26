# Identidade dos documentos técnicos

- Composição de referência: **PROJETO APRESENTADO CORRIGIDO.pdf**, páginas 24 a 27.
- Brasão de Mato Grosso permanece à esquerda; selo nacional brasileiro permanece à direita.
- Fundos: padrão institucional exclusivo gerado para o Beabá, em ameixa/cobre para diploma e terracota/creme para certificado.
- Fontes: Great Vibes e Open Sans, incorporadas ao PDF; licenças nos diretórios correspondentes em `resources/fonts`.
- Os documentos emitidos armazenam um retrato dos dados conferidos e o PDF original; alterações posteriores no cadastro não alteram a reimpressão.

Fontes públicas dos símbolos (domínio público governamental, conforme as páginas de origem):

- https://commons.wikimedia.org/wiki/File:Bras%C3%A3o_de_Mato_Grosso.png
- https://commons.wikimedia.org/wiki/File:National_Seal_of_Brazil.svg

No verso, as cores dos módulos permanecem consistentes entre os documentos: creme para o módulo I, ameixa suave para o II e terracota suave para o III. A legenda acompanha a tabela. O QR Code no canto inferior esquerdo aponta para a autenticação do próprio documento; nas prévias, a consulta identifica expressamente que o curso ainda não foi finalizado.
