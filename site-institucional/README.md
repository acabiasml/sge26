# Página pública do CTJJ

Fonte da página institucional independente do Laravel. Publicação manual por SSH/SFTP:

- `index.html` → `domains/ctjj.org/public_html/index.html`
- `assets/*` → `domains/ctjj.org/public_html/assets/ctjj-home/`

Antes de publicar, salvar cópia dos arquivos substituídos fora de `public_html`. Enviar os assets primeiro e substituir o HTML por renomeação atômica. Não alterar `.htaccess`, o diretório `sge` ou os sites legados.

Conteúdo baseado no relatório documental institucional com data de corte de 11/09/2026. As referências externas constam na própria página. Atos históricos são apresentados com seus períodos; situações atuais sem documentação confirmada não são afirmadas como vigentes.

Imagens e fonte já existentes no servidor são reutilizadas. O JavaScript implementa abas acessíveis por teclado e a consulta pública de autenticidade do Beabá. Sem JavaScript, as linhas do tempo permanecem visíveis.
